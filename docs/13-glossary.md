# 13 · Glossary

[← Troubleshooting](12-troubleshooting.md) · [Next: References →](14-references.md)

| Term | Meaning in this project |
|---|---|
| **ABI** | Rules for calling conventions, register use, data layout and binary linkage. |
| **ADPCM** | A family of compressed audio representations found in some legacy game audio data. |
| **AFS** | An archive/container format often associated with audio and other game resources. |
| **Archive** | A file containing multiple logically separate resources. |
| **Asset pipeline** | Tools and formats used to transform source content into game-ready resources. |
| **Big-endian** | Stores the most significant byte first in a multi-byte value. |
| **Branch delay slot** | MIPS execution behavior where an instruction after a branch may still execute. |
| **CLUT** | Color lookup table for indexed textures. |
| **DMA** | Direct memory access mechanism for moving data without ordinary CPU copies. |
| **EE** | Emotion Engine, the PlayStation 2's main processor complex. |
| **ELF** | Executable and Linkable Format; used in several environments, but architecture and ABI matter. |
| **GS** | Graphics Synthesizer, the PS2 graphics processor. |
| **Ghidra** | Static analysis framework with disassembly and decompilation tools. |
| **IOP** | PS2 I/O Processor responsible for separate system services. |
| **IRX** | PS2 IOP module format commonly used to provide services. |
| **Little-endian** | Stores the least significant byte first in a multi-byte value. |
| **MIPS** | Processor instruction-set family used by the PS2's main CPU. |
| **Native port** | Rebuilt software compiled and integrated directly for the target system. |
| **PCSX2** | Open-source PS2 emulator useful for observing reference behavior. |
| **PowerPC** | Instruction-set architecture family used by the Xbox 360's Xenon CPU. |
| **PSS** | A PS2-era multimedia stream/container frequently used for cutscenes. |
| **Reverse engineering** | Inferring system operation from binaries, data structures and observed behavior. |
| **RGH/JTAG** | Xbox 360 modifications enabling various homebrew execution workflows. |
| **RPC** | Remote procedure call; the PS2 EE and IOP can exchange service requests. |
| **SPU2** | PS2 sound processing subsystem. |
| **Static recompilation** | Translating already compiled code into a new compiled representation, with runtime requirements. |
| **Swizzling** | Reordering pixels/texels for a hardware-friendly memory layout. |
| **Vertical slice** | Small end-to-end implementation proving a useful part of the complete system. |
| **VU0 / VU1** | PS2 vector units used for graphics and mathematical workloads. |
| **Xenia** | Xbox 360 emulator for desktop smoke checks; not identical to physical hardware. |
| **Xenon** | Xbox 360's PowerPC-based CPU. |
| **Xenos** | Xbox 360 GPU. |
| **XEX** | Executable container for Xbox 360 titles, subject to target kernel/loader expectations. |
| **XSDK** | Independent homebrew SDK for Xbox 360 development. |
